# NIGHTSHIFT · 夜行频率

原创赛博朋克个人主页，包含原创三维城市、作品筛选与详情、个人介绍、联系入口、文章动态、内容编辑器和可玩的霓虹避车赛车。

## 在线访问与继续工作

GitHub Pages 入口：https://lexstark335-ctrl.github.io/index.html/ 。主页发布目录为仓库 `nightshift/dist/`。

后续继续开发前先阅读 `HANDOFF.md`。个人内容更新的操作步骤见 `CONTENT-GUIDE.md`。网页编辑器保存的是浏览器草稿；导出并提交 `nightshift/dist/content.json` 后才能更新公开版本。

## 运行

最快在线访问：打开上方 GitHub Pages 地址。本地交付包还包含 `双击打开主页.html`，可直接查看主页和玩赛车，无须本地服务。若从 GitHub 下载源码，先运行 `npm run standalone` 生成该文件。离线版内嵌全部代码与资料，修改保存在当前浏览器，可导出 JSON 备份。更新 `dist/content.json` 后需要重新生成离线文件。

如需将资料直接写回项目配置文件，使用下方本地服务方式。

需要 Node.js 20 或更新版本，无须安装依赖。

双击 `启动主页.cmd`，或在本文件所在目录运行：

```sh
npm start
```

浏览器打开 http://127.0.0.1:4173 。终端需保持运行，Ctrl+C 停止服务。不要直接双击 index.html；模块和配置文件需要通过 HTTP 读取。

## 后续写入个人资料

点击页面右上角或底部的「编辑内容」。

1. **个人资料**：填写姓名、身份、首屏标题、简介、关键词和联系方式。
2. **项目作品**：增删项目，填写背景、贡献、成果、分类、标签和链接，选择三种原创封面视觉。
3. **文章动态**：添加文字记录和可选的外部文章链接。列表为空时主页自动隐藏该栏目。
4. 点击「保存并更新主页」。使用本项目自带的本地服务时，修改会写入 `dist/content.json`，重新打开仍然保留。
5. 「导出当前资料」生成 `content.json` 备份；「导入 JSON 资料」先读入草稿，需保存才生效。「恢复文件中的资料」将当前文件重新载入草稿，**不是恢复原始占位版本**。

也可以直接编辑 `dist/content.json`。格式错误会提示，写入会验证资料结构和外链格式。当前所有人物介绍与项目均为明确的占位内容，不代表真实经历。

## 本地与线上保存的区别

本地服务仅绑定 `127.0.0.1`，仅接受本机同源编辑器的资料写入，不是线上 CMS。

`dist/` 可部署至静态托管平台。线上编辑器的修改仅保存在当前浏览器，其他访客不会同步看到。若需全站更新，将编辑器导出的 `content.json` 替换到 `dist/content.json` 后重新部署。用全新浏览器可查看发布文件；已保存个人覆盖内容的浏览器可用「恢复文件中的资料」重新载入。

后续如需跨设备登录、私有后台、服务器存储和附件上传，可在这版基础上增加后端；当前不含这些功能，也没有假提交表单。

## 赛车

- 入口：「夜间兜风」「启动夜行模式」，或浏览主页时按 G。
- A/D 或 ←/→：左右转向。移动端使用屏幕底部箭头，可双指同时转向和加速。
- W/↑ 或 BOOST：短时加速，结束后冷却。
- P / 空格：暂停、恢复。Enter 开始、重试或恢复。
- Esc 或右上角 ×：退出，回到主页。
- 碰撞结束，擦车获得额外分数与连击。最高分保存在当前浏览器。
- 切换后台或窗口失去焦点会暂停；音效默认关闭，开启后由 Web Audio 实时合成。

## 验证与结构

```sh
npm run build
npm test
```

本项目为无需构建的原生 ES Modules 网站；build 命令验证 JavaScript 语法、入口资源与资料格式，静态输出就是 `dist/`。

- `dist/app.js`：主页、详情、筛选、内容编辑、导入导出。
- `dist/content.js`：浏览器与本地服务共享的资料校验。
- `dist/style.css`：响应式布局、主题和组件。
- `dist/world.js`：原创三维城市、道路和车辆。
- `dist/canvas-renderer.js`：无法启用 WebGL 时的赛车兼容画面，与三维版共用玩法状态。
- `dist/visual.js`：主页背景渲染与动态效果控制。
- `dist/game.js`、`game-model.js`：赛车画面、音效、输入与玩法状态。
- `server.mjs`：本地预览和配置文件写入服务。

主页支持减少动态效果、键盘导航、焦点提示和移动端布局。没有 WebGL 时保留 CSS 城市背景，个人资料仍可阅读；赛车会自动切换到 Canvas 兼容画面，操作、计分和最高分保持一致。没有 JavaScript 时会显示使用说明，不提供完整静态内容渲染。

2026-11-01 赛车修复：移除将 `IcosahedronGeometry` 误当作 `GridHelper` 的错误库导出映射，改为显式构造网格线段；补齐主页/赛车场景初始化与禁用 WebGL 的回归测试。在线资源带修复版本标记；离线版需重新生成或刷新本地文件。
