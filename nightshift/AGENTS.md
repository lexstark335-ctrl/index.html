# 继续本项目

用户要求：下次继续时先提醒阅读 `HANDOFF.md`。

先读取 `HANDOFF.md`，简短告诉用户「我先看 HANDOFF.md，再接着处理」，然后核对实际文件和 GitHub 最新分支状态。每次完成实质改动后更新交接文档。

- 发布时保留既有仓库内其他项目和文件；仅更新主页相关路径。
- 不能把上传完成视为上线；核对 Pages 工作流结果与实际页面或发布资源。
- 不要上传凭证、临时测试文件、绝对本地路径或 `.openai/hosting.json` 等其他平台元数据。
- 中间文件使用 `work/`；使用项目提供的构建检查、测试和单文件生成命令。
