## 文件与运行方式

本地项目目录：`outputs/nightshift-homepage/`。GitHub 项目目录：`nightshift/`。

离线 HTML 是生成产物，包含在本地交付包；GitHub 源码中通过 `npm run standalone` 生成。GitHub 未上传 `.openai/`、`.git/`、测试临时目录和凭证。本地 `.git` 仅为此前尝试初始化的空仓库，尚未与 GitHub 历史同步；不要直接推送这份空历史覆盖远端。

| 文件 | 作用 |
| --- | --- |
| `dist/content.json` | 个人资料、项目、文章的主数据文件 |
| `dist/index.html`、`dist/style.css` | 页面结构、原创视觉与响应式样式 |
| `dist/app.js`、`dist/content.js` | 主页、编辑器、导入导出与资料校验 |
| `dist/world.js`、`dist/visual.js` | 原创城市、道路、车辆和背景渲染 |
| `dist/game.js`、`dist/game-model.js` | 赛车展示、输入、音效与规则 |
| `dist/canvas-renderer.js` | WebGL 不可用时的赛车兼容画面 |
| `dist/vendor/` | Three.js r184 和 MIT 许可 |
| `server.mjs` | 本机预览与写回配置文件服务，仅绑定回环地址 |
| `scripts/standalone.mjs` | 将样式、代码与资料内嵌，生成离线 HTML |
| `双击打开主页.html` | 离线预览，不需要 Node 或本地服务 |
| `启动主页.cmd` | 启动 Node 本地服务，需要 Node.js 20+ |
| `CONTENT-GUIDE.md` | 后续编辑资料和更新公开网站的操作说明 |
| `VERIFICATION.md` | 验证范围与限制 |

命令：

```sh
npm start
npm run build
npm test
npm run standalone
```

无需安装依赖。`npm start` 使用 `http://127.0.0.1:4173/`；终端/服务必须保持运行。离线版在浏览器中直接打开，支持本地草稿和 JSON 备份。更新源码或主数据后须重新生成离线文件。

## 踩过的坑

- **本机 URL 不等于公网网址。** 前一轮交付前停止了预览服务，却仍给出了回环地址，导致用户打不开。不能再把服务启动日志当成用户已可访问。
- **当前工具环境限制本机网络访问。** 测试进程访问回环端口报 `EACCES`；因此改用直接调用请求处理器验证。不能把这项替代验证包装成浏览器实测。
- **浏览器控制被停止。** Windows 浏览器网址识别失败，系统停止了控制；不得反复重试或声称已完成可视验收。
- **离线版必须真正内嵌。** 直接双击原始 `dist/index.html` 会遇到模块/读取 JSON 的浏览器限制；已新增离线打包器，将所有运行代码、样式和资料内嵌。
- **保存方式不同。** 浏览器 localStorage 只属于当前浏览器，不能同步给访客；只有更新 GitHub 主数据并发布才会全站生效。
- **其他平台发布失败。** 曾创建 Sites 项目标识，但 Git 源码同步报 DNS 线程错误，未上线；不要重复宣称已发布。此次以用户明确指定的 GitHub 为准，不上传该平台元数据。
- **临时凭证短期有效。** 曾发生源仓库凭证过期；不得将凭证落盘或写入本文件。
- **临时目录的重命名权限不同。** 系统临时目录中文件替换报 `EPERM`，工作区临时目录通过；测试使用项目 `work/` 并校验清理路径。
- **GitHub 仓库已有内容。** 初始 `main` 为 `9958e6931e01b8b9a44497102a7590f7a973e945`，含 `idex.html` 与 `stm32l552-power-lab/`。上传应基于当前树添加主页，避免覆盖其他项目。
- **GitHub 连接器可用，命令行网络不可用。** 本次改用连接器的 blob/tree/commit/ref API 提交，保留远端原有历史；未使用本地空仓库强推。大型库分段读取并核对 Git blob SHA 后上传，不在对话里打印完整代码或凭证。
- **部署成功与浏览器访问是两类证据。** GitHub 的部署日志已经报告成功并给出公开 URL；网页读取工具仍无法读取该域名。因此可以确认部署成功，不能宣称已用浏览器看过画面。
- **导出名不能凭别名猜测。** 旧 `Z as GridHelper` 实际导出的是 `IcosahedronGeometry`，导致 `grid.position.set` 处崩溃，主页背景与赛车都会失败。已移除该错误映射，以 `BufferGeometry` 和 `LineSegments` 显式构建网格；测试覆盖生产实际场景构建，不能再只测试部分车辆几何体。
- **统一错误消息会误导定位。** 旧消息把所有初始化错误都说成 WebGL 不支持。现在区分图形能力错误与程序初始化错误；无法启用 WebGL 时，赛车先自动使用 Canvas 兼容渲染。
- **用户上传资料的目录。** 已发现提交 `8232f50195e494376c2d05773d92174d003c6cb3` 新增的是 `nightshift/content.json`，网站实际读取 `nightshift/dist/content.json`。这次赛车修复不搬移或发布个人数据，保留该上传文件；后续资料更新必须核对准确路径。
